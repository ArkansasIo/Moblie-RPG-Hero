# Taskbar Hero 0.3.0

**Developer:** ArkansasIo  
**Android versionCode:** 3  
**Android versionName:** 0.3.0  
**Application ID:** `io.arkansasio.taskbarhero`  
**Release channel:** release-candidate / unsigned Android package

## Included

- RPG/MMORPG command-center menus and individual submenu pages
- Character, inventory, world, combat, quest, multiplayer, PvP, progression, economy and system sections
- RPG stat and combat calculation framework
- Enemy and boss AI framework
- Threat, cooldown, effects, loot and dungeon systems
- Guild, social, economy, marketplace and trading foundations
- New RPG item catalog
- Pixel-art hero, enemy, equipment/resource, biome and UI atlases
- Android packaging metadata and versioning
- Tagged-release workflow for generating GitHub release APKs

## APK status

The CI pipeline builds both a debug APK and an unsigned release APK. A production Android APK must be signed with the developer's private release key before store distribution.
