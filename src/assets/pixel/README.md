# Taskbar Hero Pixel Asset Pack

This folder contains scalable pixel-art source assets used as the visual baseline for the RPG/MMORPG expansion.

## Asset families

- heroes: knight, ranger, mage, priest, paladin, rogue, druid, necromancer
- enemies: slime, goblin, skeleton, skeleton knight, orc, wraith, elemental, dragon
- bosses: guardian, lich, demon, void titan, world boss
- equipment: swords, axes, bows, staves, armor, shields, rings, relics
- resources: ore, wood, herbs, crystals, leather, monster parts
- biomes: forest, plains, desert, tundra, swamp, volcanic, ocean, arcane, void
- UI: currencies, inventory, quest, map, dungeon, raid, PvP, guild, party, chat

SVG files are intentionally pixel-grid based so they can be rasterized to 16/24/32/48/64/96/128px without changing the artwork's proportions.
